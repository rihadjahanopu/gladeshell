1. PROJECT OVERVIEW
================================================================================

gladeshell is a 100% PURE RUST, ZERO-EXTERNAL-BINARY-DEPENDENCY toolkit and
modular terminal developer suite. It enhances terminal environments (Bash,
Zsh, Fish, PowerShell 7+) with sub-millisecond prompt rendering, 55 themes,
native shell completions, multi-core compression, AES-256 security vaults,
and native Ratatui TUI developer applications.

  Target Users  : Software Developers, DevOps Engineers, System Administrators
  Target Shells : Bash 4+ · Zsh 5+ · Fish 3+ · PowerShell 7+ · Elvish
  Target OS     : Linux (glibc & MUSL) · macOS (Intel & Apple Silicon) · Windows
  Install Method: Universal setup script (`install.sh`/`install.ps1`) | Cargo build
  Architecture  : Pure Rust compilation · Zero-fork telemetry · Sub-millisecond latency

5. CORE SUBSYSTEMS & TECHNICAL DETAILS
================================================================================

5a. Native Shell Auto-Completions Subsystem (`src/main.rs` & `src/init/`)
──────────────────────────────────────────────────────────────────────────
  • Powered by `clap_complete v4`.
  • Subcommand `gladeshell completions <shell>` emits native completion scripts.
  • Embedded directly into `gladeshell init <shell>` (e.g. `eval "$(gladeshell init zsh)"`)
    so completions load in-memory automatically on shell launch without writing files.

5b. Native IDE Setup Modules (`src/tools/zed_setup.rs` / `src/tools/code_setup.rs`)
───────────────────────────────────────────────────────────────────────────────────
  • Installs fully-configured, developer-optimized `settings.json` in one command.
  • Detects and updates all target paths: Native, Flatpak, Snap, and Windows AppData.
  • Creates timestamped backups before writing configuration files.

5c. Parallel Multi-Core Compressor (`src/tools/compressor.rs`)
─────────────────────────────────────────────────────────────
  • Utilizes `rayon` data parallelism thread pool.
  • Level 1 Fast default compression for maximum throughput.
  • Smart pre-compressed media detection bypasses redundant CPU compression work.

5d. Hardened Security Vault (`src/tools/vault.rs`)
──────────────────────────────────────────────────
  • AES-256-GCM authenticated encryption with 96-bit random nonces.
  • PBKDF2-HMAC-SHA256 key derivation with 100,000 iterations and 128-bit salt.
  • RAM zeroization via `zeroize` crate to scrub passwords upon drop.
  • Decoy panic password mode for emergency decoy protection.

6. BULLETPROOF CI/CD RELEASE PIPELINE (.github/workflows/release.yml)
================================================================================

  1. Version Bump Auto-Detect: On push to `main`, reads version from `Cargo.toml`.
  2. Automated Tag Creation: Creates and pushes annotated Git tag `vX.Y.Z`.
  3. Crate Publish Check: Validates crate publishability via `cargo publish --dry-run`.
  4. 7-Platform Matrix Compilation:
     • x86_64-unknown-linux-gnu    • x86_64-unknown-linux-musl
     • aarch64-unknown-linux-gnu   • x86_64-apple-darwin
     • aarch64-apple-darwin        • x86_64-pc-windows-msvc
     • aarch64-pc-windows-msvc
  5. Binary Size Stripping: Strips debug symbols (`strip`) on Unix runners.
  6. Automated Release Notes: Parses `CHANGELOG.md` for exact version notes.
