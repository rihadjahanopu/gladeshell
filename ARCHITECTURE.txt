1. PROJECT OVERVIEW
================================================================================

fancybash is a PURE RUST, ZERO-EXTERNAL-SUBSHELL-DEPENDENCY binary toolkit
and terminal environment for modern software developers. It enhances default
shell terminals (Bash, Zsh, Fish, PowerShell 7+) with sub-millisecond prompt
rendering, parallel multi-core compression, 55 TUI themes, and interactive tools.

  Target Users  : Full-stack developers, DevOps, System Administrators
  Target Shells : Bash 4+ · Zsh 5+ · PowerShell 7+ · Fish 3+
  Target OS     : Linux (glibc & static MUSL) · macOS (Intel & ARM64) · Windows
  Install Method: Universal one-liner (`install.sh` / `install.ps1`) | Cargo build
  Philosophy    : "Pure Rust compilation. Sub-millisecond latency. 100% Memory safe."

5. CORE COMPONENTS & SUBSYSTEMS
================================================================================

────────────────────────────────────────────────────────────────────────────────
5a. PURE RUST CORE ENGINE  (src/core/ & src/tools/)
────────────────────────────────────────────────────────────────────────────────

Built in 100% safe Rust with Ratatui TUI components and Rayon parallel thread pool:

  • src/tools/compressor.rs  — Multi-core parallel archive compressor (Level 1 Fast).
  • src/tools/extractor.rs   — Multi-format unpacker with stream decoding.
  • src/tools/ffmedia.rs     — 24-in-1 FFmpeg multimedia suite.
  • src/tools/vault.rs       — AES-256 PBKDF2 encrypted vault with decoy trigger.
  • src/tools/theme_picker.rs— 55-theme interactive prompt switcher.
  • src/tools/todo.rs        — Ratatui task manager with JSON persistence.
  • src/tools/notes.rs       — Terminal note editor with 2D viewport.

────────────────────────────────────────────────────────────────────────────────
5b. INSTALLER LAYER  (install.sh / install.ps1)
────────────────────────────────────────────────────────────────────────────────

  • Idempotent boundary marker injection (`# >>> fancy-bashrc >>>`).
  • SHA-256 checksum verification for downloaded release binaries.
  • Automatic timestamped backup creation before dotfile modifications.

────────────────────────────────────────────────────────────────────────────────
5c. CI/CD & AUTOMATION LAYER  (.github/ & .githooks/)
────────────────────────────────────────────────────────────────────────────────

  • .github/workflows/rust-ci.yml: Multi-OS matrix testing (Linux/macOS/Win).
  • .github/workflows/release.yml: 7-target platform release binary matrix.
  • .githooks/pre-commit: Hygiene guard, installer sync, cargo check/clippy/fmt.
  • .githooks/pre-push: Workspace compilation check & full unit test suite.


================================================================================
6. TESTING & VERIFICATION PROTOCOL
================================================================================

Contributors must run the verification suite prior to submitting pull requests:

  make check      # Run cargo check across all workspace targets
  make clippy     # Run Clippy lints with strict warning enforcement
  make fmt        # Format Rust source code
  make test       # Execute full unit test suite (43+ tests)
  make bench      # Execute Criterion micro-benchmarks
