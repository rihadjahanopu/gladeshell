Local Dev Setup in 3 Steps

Get your local environment set up and start shipping code in minutes.

1
🍴

Fork & Clone

Fork rihadjahanopu/gladeshell on GitHub, then clone your fork locally.

bash 
git clone https://github.com/rihadjahanopu/gladeshell.git && cd gladeshell
2
⚙️

Run Setup Script

Git Hooks

Pick your shell — this installs Git hooks and syncs your dev environment automatically.

bash 
bash setup.sh
zsh 
zsh setup.zsh
fish 
fish setup.fish
powershell 
.\setup.ps1
